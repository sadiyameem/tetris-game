# Tetris Game

# Description
- This game lets users to move, rotate, place and play with different kind of blocks while clearing rows to score points.

# Features
- Move blocks using arrow keys
- Different shapes and colors
- Next block preview
- Score tracker
- Game over screen
- Restart button
- Play button
- Instructions display
- Random generated blocks

# Tools
- HTML
- CSS
- JavaScript
- https://www.schemecolor.com/

# Challenges/Learned
- A challenge was getting the JS to work and getting the play and pause to work and be functional.
- I learned how to use HTML canvas and connect languages together.
